Cập nhật khi game update

Upload file Music_Login.bnk mới lên catbox.moe, dán link vào đây cùng Source ID mới (nếu có đổi).
Bnk sẽ được patch để trỏ từ Source ID sang Replacement ID này, và file .wem trong zip output cũng đặt tên theo ID này — nhờ vậy file {Source ID}.wem gốc trên máy game không bao giờ bị ghi đè, tự động đóng vai trò bản backup. Để trống thì giữ Replacement ID hiện tại (hoặc = Source ID nếu chưa từng set).
Để trống ô nào thì giữ nguyên giá trị đang active của ô đó. Cần điền ít nhất 1 ô.
⚠️ Server tải file .bnk từ link Catbox mỗi khi cache hết hạn (~30s) hoặc ngay sau khi bạn lưu cấu hình mới — nên nếu bạn XOÁ file trên Catbox mà không cập nhật link mới ở đây, lần build tiếp theo sẽ lỗi. Cấu hình (Source ID + Replacement ID + link) lưu trên Supabase nên sẽ không mất khi Render deploy lại.
